# MZG-Craft-Calcul# 

Калькулятор рецептур для **малих партій** — свічки, кашпо, гейзерні модулі, тестові відливки.
Це **не** ERP і не інструмент масштабного промислового виробництва. Один оператор, локальні дані,
офлайн-робота на телефоні. Філософія MZG Universe: *«Нічого не викидається — все трансформується»*.

> PWA · IndexedDB · offline-ready · Android + будь-який браузер · без серверної реєстрації користувача.

---

## Для чого

- зібрати рецептуру з реальних матеріалів цеху (віск, наповнювач, зв'язуюче, добавка, барвник, аромат, ґнот, упаковка);
- порахувати масу кожного компонента в партії, вихід виробів і собівартість (COGS);
- зберегти перевірені рецепти та швидко повертатися до них наступної зміни;
- додати новий матеріал у двох кліках, без залежності від розробника.

## Архітектура

Односторінковий PWA з чотирма файлами в корені репо:

    index.html            інтерфейс + уся логіка + локальна БД (IndexedDB)
    manifest.webmanifest  метадані для встановлення на головний екран
    sw.js                 Service Worker: кешування оболонок, офлайн-режим
    icon.svg              іконка застосунку

Дані (матеріали, рецепти, налаштування) зберігаються **виключно на пристрої** у IndexedDB.
Сервера для облікових записів немає. Логіна немає. Інтернет потрібен лише для першого
завантаження сторінки та для оновлення файлів після деплою.

## Модулі

| Вкладка     | Призначення                                                                 |
|-------------|-----------------------------------------------------------------------------|
| Калькулятор | збірка рецепту, режим `% маси` та `на виріб`, розрахунок партії й COGS     |
| Матеріали   | довідник сировини: пошук, фільтр за категорією, додавання / редагування     |
| Рецепти     | збережені формули: завантажити, копіювати, видалити                         |
| Налаштування| цехові параметри (втрати, енергія, праця, QC, роялті) + експорт/імпорт JSON |

### Формула собівартості

    COGS = сировина + витратники + енергія + праця + QC + роялті

Для ремісничого цеху енергію, працю, QC і роялті можна ставити `0`, щоб не ускладнювати облік.

## Деплой на GitHub Pages

1. Завантаж у корінь репо рівно чотири файли: `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
   Перетягуй **виділені файли**, а не теку, щоб не отримати вкладеність `/MZG-Craft-Calc/...`.
2. Перевір перший рядок `index.html` — він має бути рівно `<!DOCTYPE html>`.
   Якщо бачиш `PK` або незрозумілі символи — файл збережено як Word-документ, переведи в plain text
   (Acode / VS Code / Notepad++, кодування UTF-8 без BOM).
3. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
4. Через 1–2 хвилини сайт доступний за адресою `https://<логін>.github.io/<репо>/`.

## Встановлення на Android

1. Відкрий кореневу адресу в **Chrome** (не інкогніто), з інтернетом, побудь на сторінці 10–15 с —
   за цей час Service Worker закешує оболонку.
2. Меню `⋮` → **Встановити застосунок** / **Додати на головний екран**.
3. Офлайн-тест: вимкни Wi-Fi і мобільний інтернет → закрий застосунок свайпом → відкрий з іконки.
   Має завантажитись інтерфейс і збережені дані.

## Дані та резервні копії

Дані живуть тільки в IndexedDB телефону. Очищення даних сайту в браузері їх видаляє.
Тому після кожної робочої зміни — **Налаштування → Експорт JSON** → файл у Drive / Telegram.
Відновлення на іншому пристрої: **Імпорт JSON**.
